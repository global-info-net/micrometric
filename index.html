Understanding common micro-unit conversions

Small measurement differences can matter in web layouts, application development, print preparation, engineering calculations and data handling. A consistent conversion reference helps reduce manual calculation errors.

CSS pixels are reference units rather than a guarantee of physical screen dimensions. A REM value depends on the root font size configured by a website. For data sizes, decimal megabytes and binary mebibytes are different units; select the appropriate option for the specification you are following.

Frequently asked questions

How many pixels are in one centimeter?

Using the CSS reference of 96 pixels per inch and 2.54 centimeters per inch, one centimeter equals approximately 37.7953 CSS pixels.

How do I convert milliseconds into seconds?

Divide milliseconds by 1,000. For example, 2,500 milliseconds equals 2.5 seconds.

How many millimeters are in one inch?

One international inch equals exactly 25.4 millimeters.

What is the difference between MB and MiB?

A megabyte (MB) is 1,000,000 bytes in decimal notation. A mebibyte (MiB) is 1,048,576 bytes using binary notation.

How does the pixels to REM conversion work?

The calculator divides the pixel value by the assumed root font size of 16 pixels. If your website uses another root font size, the result will differ.

What does the numerical multiplier do?

The multiplier scales the entered value before conversion. For example, an input of 10 with a multiplier of 3 is converted as 30 units.
